# 🛒 E-Commerce Websites

A collection of modern, responsive **E-Commerce website templates** built for different business types and brands.

This repository contains ready-to-use website templates that can be customized for real-world online stores, portfolios, startups, and client projects.

---

## 📦 Templates

| Template | Type | Description |
|----------|------|-------------|
| 🥬 **Angithi Veg** | Grocery / Fresh Produce | A modern online vegetable & grocery shopping experience |
| 🛍️ **Kirana Store** | Grocery / General Store | A complete Indian neighbourhood-store inspired e-commerce website |
| ✨ **NovaKart** | General E-Commerce | A modern multi-category online shopping template |

> More templates may be added to this collection over time.

---

## 🚀 Features

Depending on the template, the websites include features such as:

- 📱 Fully responsive design
- 🛍️ Product listings & product cards
- 🔎 Product search
- 🗂️ Category filtering
- 💰 Pricing, MRP & discounts
- ⭐ Product ratings & reviews
- 🛒 Shopping cart
- ❤️ Wishlist
- 👁️ Product quick-view
- 📦 Order management UI
- 🎟️ Coupon / offer sections
- 💳 Checkout & payment UI
- 📍 Delivery / pincode checking
- 🌙 Dark mode
- 📱 Mobile navigation
- 🔔 Toast notifications
- ❓ FAQ sections
- 💬 Customer testimonials
- 🔝 Back-to-top controls
- ⚡ Smooth and interactive UI
- 🎨 Easily customizable branding
